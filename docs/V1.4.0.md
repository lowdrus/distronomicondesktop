# DISTROD v1.4.0

Esta versão concentra melhorias de segurança, recuperação e experiência de uso no Windows.

Principais mudanças: correção automática quando `owner/repository` é colocado no campo Aplicação; menu Configurações; backup configurável antes do update; canais Stable/Beta/Nightly; notificações do Windows; abertura da pasta ativa e página de releases; Authenticode; retenção por quantidade, dias e espaço; reconstrução de estado; importação/exportação de perfis; log técnico separado; teste de conectividade; seleção x64/ARM64/x86; proteção contra downgrade; release notes na GUI; cancelamento seguro; e estimativa de espaço.

A distribuição continua portátil. O usuário final não precisa executar Cargo, PowerShell, WSL ou comandos de terminal para o fluxo normal.

Antes de uma release ser promovida, o Windows CI precisa passar rustfmt, Clippy, testes, build MSVC com CRT estático, validação do executável/ícone e geração do pacote portátil.
