# Distronomicon Desktop

Interface web simples para o [Distronomicon](https://github.com/jtdowney/distronomicon).

## O que faz

- Formulário amigável para aplicação e repositório GitHub
- Gera comandos `check`, `version` e `update`
- Copia o comando pronto para execução no Ubuntu/WSL
- Interface responsiva hospedável no Vercel

> O Distronomicon original é um binário Linux. Por segurança e pelas limitações do navegador, a versão web não executa comandos locais no WSL diretamente; ela funciona como painel/gerador de comandos.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
